НОВОГОДНИЕ ПРЕДМЕТЫ — Fabric / Minecraft 1.21.1

В проекте есть 8 предметов:
Шапка Санты, синяя зимняя шапка, шапка эльфа, снежная шапка,
золотая праздничная шапка, новогодняя гирлянда, звезда на ёлку
и ёлочные украшения.

Все новые предметы имеют блочные 3D-модели из кубов в стиле Minecraft.
Предметы добавлены в творческую вкладку «Инструменты и утилиты».

Сборка:
- Minecraft Java 1.21.1
- Fabric Loader + Fabric API для 1.21.1
- Java 21
Открой проект как Gradle-проект и запусти задачу build.
JAR будет в build/libs/.

Примечание: гирлянда, звезда и украшения сейчас являются 3D-предметами
для инвентаря/руки. Это не размещаемые блоки и они не крепятся автоматически
на ёлку. Для размещения в мире потребуется отдельная логика блоков/декораций.

Салаты добавлены в творческую вкладку «Еда и напитки».

МЕБЕЛЬ И СЕРВИРОВКА:
- Новогодний стол
- Красная скатерть
- Четыре декоративные тарелки с салатами

Стол, скатерть и тарелки — размещаемые блоки. Салаты в тарелках являются
декоративными блоками; съедобные версии салатов остаются отдельными предметами.
Поставь стол, затем поставь скатерть рядом/на поверхность как отдельный блок,
а тарелки — на столешницу. (Проверка корректного размещения поверх стола
в игре ещё необходима.)

НОВОГОДНЯЯ ПИЖАМА:
- Колпак
- Кофта
- Штаны
- Тапочки

Четыре предмета зарегистрированы как надеваемые в соответствующие слоты:
голова, торс, ноги и ступни. В этой версии есть пиксельные иконки предметов;
отдельная полноценная модель/текстура комплекта на теле игрока ещё требует
добавления equipment-asset и проверки в Minecraft.


НОВОЕ: МУЗЫКАЛЬНЫЕ ПЛАСТИНКИ
Добавлены три оригинальные инструментальные мелодии:
- Пластинка «Новогодний огонёк»
- Пластинка «Зимний вальс»
- Пластинка «Фейерверк»

Пластинки воспроизводятся в обычном Minecraft-проигрывателе (jukebox).
Мелодии созданы специально для этого мода и не являются записями известных песен.


НОВОЕ: БЛОК СНЕГОВИКА
Добавлен декоративный блок «Снеговик».
Рецепт: верхний ряд — уголь, морковка, уголь; под ними — два снежных блока друг под другом.
Это крафтовый декоративный блок; он не оживает и не собирается автоматически из блоков в мире.


НОВОЕ: ПОСТОЯННЫЙ НОВОГОДНИЙ СНЕГОПАД
При запуске мира новогодний снег включён автоматически. Снежинки появляются вокруг игроков во всех измерениях.
Команды:
- /nyhsnow off — выключить снегопад.
- /nyhsnow on — включить снегопад снова.
- /nyhsnow status — проверить состояние.
Команда доступна игрокам с правами на выполнение команд (в одиночном мире с включёнными читами или операторам сервера).
Снегопад декоративный: частицы не образуют снежный слой на земле.


НОВОЕ: ПОДАРКИ
Добавлены три декоративных подарочных блока: красный, зелёный и синий.
Каждый подарок можно скрафтить из шерсти соответствующего цвета, бумаги и золотого самородка:
- средний ряд: бумага — золотой самородок — бумага;
- шерсть соответствующего цвета размещается сверху и снизу по центру.
Подарки можно ставить как обычные блоки. Они декоративные и пока не открываются.


САНКИ:
- Предмет: Санки (sled).
- Рецепт: верхний ряд — палка, пусто, палка; средний ряд — три еловые плиты; нижний ряд — снежный блок по центру.
- Это функциональная первая версия на основе двухместной лодки Minecraft: один игрок управляет, второй может сесть пассажиром.
- Внешний вид и физика пока используют стандартную деревянную лодку; отдельная 3D-модель санок и снежное скольжение ещё не реализованы.
